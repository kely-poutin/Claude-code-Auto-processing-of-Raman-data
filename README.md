# claude-code-实现拉曼数据处理

适用场景：文件夹内有多个 BWSpec 光谱仪导出的 txt 文件，需将所有 txt 数据 导入同一个 xlsx 文件，再导入 Origin 生成拉曼光谱折线图。

解决问题：正常手动处理 BWSpec 光谱仪导出的 txt 处理拉曼数据，处理10组txt数据需要大约15分钟，现在通过我编辑的指令文案和Python代码只需要45秒即可在Origin中实现折线图的生成。甚至可以在此基础上设置每个实验数据的偏移量，直接让Origin输出tif图片文件。

环境要求：要求电脑运行环境需要有claude code、Python、Excel、Origin。

待改进点：可增加拉满数据平均值的设置，生成第二个平均值数据的图片并输出tif。（由于作者实验需要对拉曼峰值进行观测，所以自动化实现代码未加入生成tif图片的指令，需要的话建议通过附件说明的指令文案对原本指令文案进行指令增加）

附件指令：若要实现tif图片输出建议通过以下指令：
    通过 find_graph() 方法获取Graph页面对象，调用其 activate() 激活图窗口，然后调用 save_fig(完整tif路径, "tif") 导出tif图片。
